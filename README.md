# Computer Science Notes

An organized study archive for B.Tech Computer Science coursework, university
previous-year questions, interview preparation, IELTS practice, and hands-on
programming examples.

The repository is intentionally asset-first: most material is stored in its
original format so it can be opened offline and reused for revision.

## Suggested study workflow

1. **Find the syllabus** for the subject before opening notes.
2. **Study one module at a time** and keep the relevant examples nearby.
3. **Attempt the previous-year questions** without looking at the solution.
4. **Review gaps** using the notes, lab files, or linked practice material.
5. **Track progress outside the archive** so the original files remain unchanged.

For quick revision, start with the most recent semester folders and use the
older 2023 archive when you need alternate explanations or additional examples.

## Repository conventions

- Original filenames and folder structures are retained where possible.
- Spaces and punctuation in names are normal; use URL-encoded links when
  linking to files from Markdown.
- Large media and archive formats are excluded from new Git changes by
  [`.gitignore`](./.gitignore). Existing tracked assets are not removed.
- Binary study material should not be converted or recompressed unless there is
  a clear accessibility or maintenance benefit.

## Safety and responsible use

Some folders contain demonstrations of keylogging, forensic analysis, and
security-related techniques. Use those examples only in an authorized,
isolated lab environment. Do not deploy monitoring or collection code on
devices, accounts, or networks without explicit permission.

The repository may also contain downloaded educational media and third-party
course material. Respect the original authors' licenses and use the files for
personal study unless redistribution is explicitly permitted.

## Contributing

When adding material:

1. Put it in the closest existing subject, semester, or preparation folder.
2. Use a descriptive filename with the subject and module when the original
   name is unclear.
3. Avoid committing generated binaries, IDE output, secrets, or duplicate
   downloads.
4. Update this README when adding a new top-level collection.

This archive is a study aid, not a replacement for official university
syllabi, examination notices, or course requirements.
